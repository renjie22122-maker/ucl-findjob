# 05 前端设计

> 版本：v1.0 ｜ 状态：待评审

## 1. 页面路由与信息架构

| 路由 | 页面 | 核心内容 |
| --- | --- | --- |
| `/` | 看板 Dashboard | 统计卡片、状态分布、趋势图、转化漏斗、今日提醒入口 |
| `/applications` | 申请列表 | 筛选工具栏 + 表格 + 批量操作入口 |
| `/applications/:id` | 申请详情 | 基本信息、状态操作、时间线、提醒管理 |
| `/companies` | 公司管理 | 公司表格 CRUD |
| `/today` | 今日待办 | 过期/今日/未来 3 天提醒，一键完成 |
| `/sources` | 数据源 | 爬虫数据源选择、抓取参数、结果预览与勾选导入 |
| `/email` | 邮件分析 | 触发分析、提取结果卡片列表、应用/忽略 |
| `/settings` | 设置 | 邮箱与 LLM 配置、Excel 导入导出、模板下载、数据备份说明 |

全局布局：左侧导航（Logo + 菜单 + 今日提醒/待处理邮件角标）+ 内容区。响应式：窄屏（< 768px）导航折叠为抽屉。

## 2. 页面设计

### 2.1 看板 `/`

```
┌────────────────────────────────────────────────────────┐
│ 统计卡片行：总投递 | 进行中 | Offer | 今日待办(可点击)  │
├───────────────────────────┬────────────────────────────┤
│ 状态分布（横向条形/环形图） │ 转化漏斗（投递→面试→Offer）│
├───────────────────────────┴────────────────────────────┤
│ 近 30 天趋势折线图（投递/面试/Offer/被拒 多序列）       │
├────────────────────────────────────────────────────────┤
│ 最近更新列表（前 10 条，点击跳详情）                    │
└────────────────────────────────────────────────────────┘
```

- 统计卡片点击 → 跳转 `/applications` 并带上对应筛选（F11 下钻）；
- 数据通过 TanStack Query 每 30s 自动刷新 + 窗口聚焦时刷新（"实时"体验）。

### 2.2 申请列表 `/applications`

- 筛选栏：状态（多选）、公司（搜索选择）、岗位类型、优先级、关键词、排序；
- 表格列：公司、岗位、状态（彩色标签）、优先级、渠道、投递日期、截止日期（过期高亮红）、更新时间；
- 行内快捷操作：「推进状态」下拉（只展示合法流转项）、「提醒」；点击行 → 详情；
- 空态引导：引导去新建或导入 Excel。

### 2.3 申请详情 `/applications/:id`

- 顶部：公司 + 岗位 + 状态标签 + 优先级；操作区：状态流转按钮（合法目标 + 打开弹窗填备注/时间）、编辑、删除；
- 中部：基本信息卡片（渠道、JD 链接可点击、截止日期、投递日期、备注）；
- 右侧/下方：时间线（状态变更自动事件 + 手动笔记，按时间倒序，支持追加笔记）；
- 提醒卡片：该申请关联提醒列表 + 新建提醒。

### 2.4 今日待办 `/today`

- 三区展示：已过期（红色）、今天、未来 3 天；
- 每条：类型图标、标题、关联申请（点击跳详情）、完成按钮；
- 顶部进度条「今日已完成 x/y」。

### 2.5 公司管理 `/companies`

- 表格：名称、行业、城市、官网、备注、投递数（子查询展示）；
- 新建/编辑弹窗表单；删除需确认（提示级联删除申请）。

### 2.6 设置 `/settings`

- 导入卡片：上传 .xlsx → 显示导入结果（成功/跳过/错误行明细）；
- 导出卡片：按筛选条件导出（与列表共用筛选状态）；
- 模板下载链接；数据库文件路径与备份说明。

### 2.7 数据源 `/sources`（v1.1 更新）

- 数据源卡片（v1：牛客网）：说明 + 合规提示（仅限个人学习，已限速，遵守 robots 约定）；
- 抓取表单：关键词、类型（校招/实习）、页数（默认 3，上限 10）、**「抓取后自动导入」开关**（F17：开启后抓取完成直接入库并弹结果，关闭则预览勾选）；
- 结果预览表格：公司、岗位、薪资、城市、类型、JD 链接（可点击）、复选框；
- 操作区：全选/反选、导入选中（调用 import/records）、显示导入结果（成功/跳过明细）；
- 与库中已有申请重复的记录行标记「已存在」，默认不勾选；
- **定时自动抓取卡片**（F15）：任务列表（关键词/类型/页数/频率/启用开关/上次运行/操作），新建/编辑任务弹窗，立即运行按钮，可展开最近 10 条运行历史（状态/抓取数/导入数/去重数/错误）。

### 2.8 邮件分析 `/email`

- 顶部操作区：时间范围（7/14/30 天）+「分析邮件」按钮 + **「批量应用高置信度（≥0.8）」按钮**（F16）；未配置邮箱/Key 时显示引导跳转设置；
- 分析中：loading 态显示阶段文案（拉取邮件 → 初筛 → AI 提取）；
- 结果列表（按状态 Tab：待处理/已应用/已忽略）：每张卡片含
  - 邮件原文信息：主题、发件人、时间、摘要（可展开）；
  - 提取结果：公司、事件类型（彩色标签）、时间、岗位、置信度（Progress 或星级）；
  - 操作：「应用到追踪」「忽略」；提取结果可在弹窗中编辑修正后再应用；
- 批量操作：一键应用全部置信度 ≥ 0.8 的待处理项；
- 导航角标：待处理数量。

### 2.9 设置 `/settings`（v1.1 更新）

- 邮箱配置卡片：认证模式切换（授权码/应用密码 | Outlook OAuth2）；
  - 密码模式：IMAP 服务器/端口/TLS/账号/授权码/文件夹 + 「测试连接」按钮（附 QQ 邮箱/163 授权码获取指引）；
  - OAuth2 模式：账户类型（consumers/organizations/common）+ Client ID + 「连接 Outlook」→ 设备码弹窗（验证码大字号展示 + 微软登录链接 + 自动轮询授权状态，成功显示已连接邮箱 + 断开按钮），附 Azure 应用注册三步指引；
- AI 配置卡片：Base URL（默认 DeepSeek）/模型/API Key + 「测试连通」按钮 + 隐私提示（邮件内容仅在分析时发送给所选服务）；
- 导入导出卡片（同 2.6 原设计）与备份说明；
- **出站调用审计卡片**（v1.3）：类型过滤（爬虫/邮件/AI/微软授权/链接解析）+ 分页表格（时间/类型/目标/发送内容摘要/结果/耗时），一键刷新与清空；凭据永不记录。

## 4. 状态管理策略

- **服务端状态**：TanStack Query 统一管理，key 按资源+筛选参数组织（如 `['applications', filters]`）；任何写操作（流转/新建/删除）后精准 invalidate `['applications']`、`['stats']`、`['today']`；
- **UI 状态**：zustand 存列表筛选条件、主题等，与后端状态分离；
- **领域常量**：状态枚举/颜色/中文映射定义在 `client/src/utils/constants.ts`，与后端 `domain/status.ts` 保持注释同步（构建期可由脚本生成，v1 手动同步）。

## 5. 交互与视觉规范

- 主题：Ant Design 默认 + 品牌色（科技蓝 `#1677ff` 基调，状态色语义化：进行中=蓝、成功=绿、失败=红、提醒=橙）；
- 表格行悬浮高亮，状态标签固定色板：终态灰、Offer/签约金绿、被拒红；
- 所有删除/不可逆操作需二次确认（Popconfirm/Modal）；
- 表单校验即时反馈（AntD Form 规则 + Zod 共享 schema 思路）；
- 加载态：表格 Skeleton、图表空态占位；错误态：message + 重试按钮。

## 6. 性能与体验

- 列表分页（默认 20/页），避免全量渲染；
- 看板图表数据量 ≤ 30 点/序列，无需降采样；
- `/` 与 `/today` 30s 轮询 + focus 刷新；其余页面按需 fetch；
- 路由懒加载（React.lazy）按页面分包。
