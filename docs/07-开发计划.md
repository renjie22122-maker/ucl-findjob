## 3. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 牛客网页面结构变化/反爬升级 | 爬虫失效 | 解析器与限速参数独立成模块，失效只影响该数据源；抓取失败返回明确错误；后续可切独立脚本方案 |
| 邮箱服务商 IMAP 差异/授权码获取门槛 | 邮件分析不可用 | test-email 端点给出明确错误；设置页附 QQ/163 授权码指引；未配置时邮件页显示引导不报错 |
| LLM 不可用/未配置 Key | 提取质量下降 | 本地规则降级 + 置信度标注；提取结果全部人工确认后才应用（ADR-7） |
| better-sqlite3 原生模块安装失败 | 后端无法启动 | 锁定 Node 20+；提供 node-gyp 依赖说明；备选方案：切 `sql.js` |
| LinkedIn 抓取或自动投递违反平台规则 | 账号受限、接口失效或合规风险 | 只提供搜索词复制与用户主动粘贴岗位；不登录、不抓取、不模拟操作；正式 API 仅在取得合作伙伴权限后接入 |
| 状态机规则与实际流程不符 | 流转受限 | 规则集中在单一文件，便于按需微调；提供 reopen 兜底 |
| Excel 日期格式多样 | 导入解析错误 | 兼容日期数字序列值与字符串两种格式，行级容错跳过 |
| ECharts 包体积 | 首屏变慢 | 按需引入（echarts/core + 需要的 chart/组件），路由懒加载 |

## 4. 验收清单（最终交付标准）

1. `pnpm install && pnpm dev` 一键启动，浏览器打开 5173 即可使用；
2. 可完整走通：新建公司 → 新建申请 → 状态流转（含非法流转被拒）→ 时间线留痕 → 创建提醒 → 今日待办完成；
3. 看板统计数字与列表数据一致（抽查对账）；
4. Excel 模板导出 → 填写 → 导入 → 再次导出，数据无损往返；
5. 爬虫链路走通：数据源页抓取牛客网关键词职位 → 预览勾选 → 导入 → 列表可见；
6. 邮件分析链路走通（配置邮箱与 Key）：分析 → 提取结果可编辑 → 应用 → 时间线笔记 + 提醒生成；无 Key 时规则降级可用；
7. JD 链接解析可预填官网投递表单；
8. 全部接口对错误输入返回 4xx 而非 500；
9. `pnpm build && pnpm start` 生产模式单端口可用。
10. 可由简历创建搜索画像并生成推荐；LinkedIn 手动岗位可本地评分并导入，且系统不会自动访问 LinkedIn。

- **v1.1（自动化增强）**：定时自动抓取（crawl_jobs/crawl_runs + 调度器，F15）、邮件批量自动应用（F16）、爬虫免确认一键导入开关（F17）；新增 8 个单测（共 28 个）；端到端实测：定时任务抓取 20 条 → 自动导入 18 条（2 条去重）。
- **v1.2（Outlook OAuth2）**：微软已停用 Outlook 基本认证，新增设备码流程（start/poll/disconnect + token 自动刷新 + id_token 邮箱解析）+ imapflow XOAUTH2；新增 4 个单测（共 32 个）；实测设备码请求到达 login.microsoftonline.com（错误路径返回 AADSTS700038，真实授权需用户 Azure 应用 + 账号）。
- **v1.3（出站调用审计）**：audit_logs 表 + 五个出站点（爬虫/IMAP/LLM/OAuth2/JD 解析）全量埋点（目标/发送内容摘要/结果/耗时，凭据永不记录，保留 2000 条）；设置页审计面板（类型过滤/分页/清空）；新增 3 个单测（共 35 个）；实测真实爬虫 + JD 解析 + OAuth2 错误路径三条记录完整落库。
- **v2.0（求职增强）**：
  - M7 简历管理：resumes 表（v4 迁移）+ 结构化表单/粘贴文本 AI 解析/GitHub 主页导入（公开 API）/学位证毕业证图片识别（需视觉模型，DeepSeek 文本模型不支持时明确提示）/AI 生成与按岗位微调/HTML 导出（浏览器打印为 PDF）+ 申请关联简历版本；
